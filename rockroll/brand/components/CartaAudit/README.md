# CartaAudit

Una card per ogni area dell'audit: timbro, titolo, cosa abbiamo visto, direzione.

- Tre o quattro card per sezione, nella griglia `rr-griglia`.
- `testo`: un fatto verificato sul sito, detto in parole semplici (niente «SEO on-page», sì «Google non sa cosa vendete»).
- `direzione`: cosa proponiamo, in una riga.
- Almeno una card per audit va timbrata `da-tenere`.
