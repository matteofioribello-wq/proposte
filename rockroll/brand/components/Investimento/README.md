# Investimento

La tabella dei prezzi: voce, cosa comprende, prezzo, riferimento di mercato; sotto, la promessa sul prezzo.

- Prima del brief i prezzi sono forchette («2.800–3.600 €»); dopo il brief, nella stessa pagina, diventano prezzi fissi.
- `mercato`: la fascia di mercato con fonte citata nella pagina. Le nostre forchette stanno nella fascia bassa-media.
- `extra: true` per le voci opzionali (gestionale, area B2B, altri siti, SEO continuativa): fondo acciaio ed etichetta «Opzionale».
- `impegno` è obbligatorio nella sostanza: ogni proposta rassicura il cliente sul prezzo. Puoi riscriverlo, non toglierlo.
- La manutenzione è un canone mensile con ore incluse, su una riga a sé.
- Prezzi sempre IVA esclusa, formato italiano (punto per le migliaia, € dopo la cifra).
