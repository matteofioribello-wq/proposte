# Bottone

Bottone o link d'azione, in maiuscolo condensato.

- `primario` (giallo) una sola volta per schermata, per l'azione che conta: «Compila il brief», «Accetto la proposta».
- `secondario` per le alternative su fondo chiaro; `su-scuro` per le alternative sulla hero o nel box Brief.
- Verbo all'inizio, massimo quattro parole. Con `href` diventa un link.
