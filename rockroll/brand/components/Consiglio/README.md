# Consiglio

Il box giallo «Il nostro consiglio»: la presa di posizione dello studio. È la nostra firma, la cosa che un'agenzia generica non mette.

- Dopo ogni sezione in cui il cliente deve scegliere una direzione: audit, esperienza d'acquisto, Google, altri siti, tempi.
- `titolo` è la posizione in una frase netta; `children` la spiega in due o tre righe.
- Firma predefinita «Matteo & Simone». Con una sola persona, il suo nome.
- Massimo tre per pagina, sennò il giallo smette di essere un segnale.
