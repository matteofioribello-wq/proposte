# PiePagina

La chiusura di ogni pagina: plettro, nome e payoff, email di contatto selezionabile, validità.

- `email`: testo selezionabile, non un link mailto (nelle pagine-artefatto non è affidabile).
- `validita`: di solito «30 giorni».
- Per ora niente dati fiscali dello studio: arriveranno quando lo decidete.
