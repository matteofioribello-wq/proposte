# Fasi

Le quattro fasi di lavoro, con il lessico d'officina: Collaudo, Progetto, Officina, Consegna. L'ultima è sempre su ghisa: è il traguardo.

- Le fasi predefinite vanno bene per un sito; per CRM o automazioni cambia solo i testi, non i nomi.
- `quando`: la finestra di tempo («2 settimane», «entro fine novembre»). Le date vere stanno nella sezione tempi.
